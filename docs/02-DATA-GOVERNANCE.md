# مصادر البيانات وحوكمتها

## Asset / instrument

`asset_id=XAUUSD` منطقيًا، مع `broker_symbol`, `broker_server`, `contract_size`, `tick_size`, `tick_value_profit`, `tick_value_loss`, `volume_min`, `volume_step`, `digits`, `currency_profit`, `time_zone_policy` محفوظة بتوقيت سريانها. لا تفترض عقدًا عالميًا ثابتًا للذهب أو قيمة ثابتة للدولار لكل Tick.

## مصادر البيانات البحثية

1. MT5 الوسيط: بيانات الأسعار والسبريد والعمولات ومعلومات العقد، وتواريخ السيرفر؛ لا تخزن بيانات الحساب الخاصة ضمن Git.
2. Dukascopy: تاريخ XAUUSD لأغراض البحث، ليس بديلاً نهائيًا عن أسعار وسيط التنفيذ.
3. FRED وALFRED: الفائدة، DXY/مؤشرات الدولار عند التوفر، العائد الحقيقي، إصدارات البيانات مع تواريخ نشرها ونسخها.
4. CFTC COT: مرجع تموضع أسبوعي مع وقت الإعلان، لا تفترض أنه كان معروفًا في أسبوع القياس قبل نشره.
5. News releases: المصدر/وقت النشر والنسخة الأصلية وبصمتها.

## تدفق البيانات

- `raw` غير قابل للتعديل مع SHA256 وsource/export metadata وsource timestamp وingest timestamp.
- `validated` إصدار مشتق؛ توثق فجوات السوق وتكرارات الصفوف والشذوذ والسبريد والإطار الزمني.
- `features` لا تشاهد المستقبل، و`available_at_utc` يسبق وقت القرار.
- `labels` مستقبلية بطبيعتها وممنوعة في features أو البيانات الحية.
- `splits` مع purge/embargo/holdout غير قابل للتغيير بعد تسجيل التجربة.

## سياسة الوقت

حقول `bar_open_server`, `bar_close_server`, `available_at_utc`, `event_published_at_utc`, `ingested_at_utc`. سياسة تحويل توقيت الخادم إلى UTC يجب أن تكون محددة/مراجعة مع DST إن وجد؛ لا تستنتج UTC من MQL5 CSV الافتراضي.

## Data quality gates

- اكتمال الأعمدة والأنواع، OHLC plausible، لا أسعار غير منتهية/سالبة، لا شموع مكررة.
- تفسير gaps: عطلات/جلسات/انقطاع، لا ملء قيم سوقية مصطنعة.
- منع دمج بيانات لم تكن متاحة عند وقت الإشارة، وحظر survivorship/look-ahead.
- مقارنة broker-vs-reference، سياسة اختلاف السبريد/السعر وفروق الوقت موثقة.
- أخذ بيانات Tick حيث يلزم لحسم ترتيب لمس وقف/هدف داخل شمعة؛ عند غيابها يتم الحساب محافظًا.
- الحفاظ على `bid` و`ask` بدل افتراض التنفيذ بسعر mid.

## تخزين ومصدر البيانات

البيانات الكبيرة وأي بيانات خاصة تبقى محليًا/في object storage مرخص، تحت DVC أو content-addressed hashes. ملفات Git تحدد manifest ومسارات التجزئة فقط. لا تدفع CSV/Parquet خامًا إلى GitHub قبل فحص الخصوصية وبيانات الحساب.

نطاق العمل الحالي موثق في [الأولويات الهندسية](36-ENGINEERING-PRIORITIES.md):
لا مراجعات حقوق إضافية؛ يبقى التحقق من المصدر والبصمات والتوقيت والجودة مطلوبًا.
