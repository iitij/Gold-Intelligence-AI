# ميثاق المشروع / Project charter

**Project:** Gold Intelligence AI · **Scope:** XAUUSD spot/CFD symbol mapping only · **Status:** pre-research · **Decision owner:** project maintainer.

## الهدف

بناء منظومة **محلية وقابلة للتدقيق** تتعلم من الذهب وحده، تنتج احتمالات معايرة، وتربط النتائج بمجلس وكلاء محلي، وتعرض إشارات مع إمكانية `NO_TRADE`، ثم تختبر التنفيذ على حساب تجريبي قبل التفكير بالإنتاج.

## ضمن النطاق

- XAUUSD فقط، مع أسماء وسيط بديلة موثقة (`XAUUSDm` وغيرها) وربطها برمز منطقي واحد.
- منصة بحث للبيانات التاريخية وبيانات Tick وBid/Ask والتكاليف ومواعيد نشر الأخبار.
- تعلم إشرافي LightGBM وCatBoost؛ مقارنات Chronos-2 وNHITS؛ تخصيص Qwen عند وجود بيانات تدريب مناسبة.
- وكلاء محليون للتحليل وتفسير القرار، وليس التحكم غير المقيد بالتنفيذ أو الحدود المالية.
- Walk-forward وتقييم محمي من تسرب المستقبل، Reproducibility وCI وأرصدة/أوامر تجريبية فقط.
- ملكية صيانة كل نسخة source/vendor مجمدة؛ عدم سحب upstream بشكل آلي لاحقًا.

## خارج النطاق في الإصدار الأول

- أي وعود بعائد ثابت، أو استخدام حساب حقيقي، أو استراتيجية high-frequency؛ التداول على أصول أخرى.
- بيع إشارات أو إدارة أموال الآخرين، أو الاستنتاج بأن أداة مفتوحة المصدر آمنة بدون تدقيق.
- تدريب LLM بمليارات المعاملات من نقطة الصفر، أو رفع أوزانه الثقيلة على GitHub.
- استخدام بيانات/نماذج غير مرخصة، أو تحليلات تعتمد على المستقبل.

## مؤشرات قبول البحث

جودة البيانات موثقة؛ نتائج تاريخية مستقلة محمية؛ فرصة اقتصادية إيجابية بعد تكاليف محافظة مع فواصل ثقة وعدم انحياز للاستراتيجيات المجربة؛ سجل أسباب رفض الصفقات؛ نجاح اختبارات انقطاع الاتصال والمضاعفات والتقريب؛ وتقييم بشري قبل كل قرار نشر.

## مبادئ غير قابلة للتفاوض

1. **Fail closed:** لا بيانات/نموذج/وسيط موثوق = لا صفقة.
2. **Human in the loop** في الحساب التجريبي الأول؛ لا صلاحية تنفيذ للـ LLM مباشرة.
3. **No look-ahead:** الخصائص والسياق يجب أن يتوفرا فعلاً لحظة القرار.
4. **Reproducibility:** ربط النتائج بـSHA الكود والبيانات وإعدادات التجربة.
5. **Provenance:** كل ملف مستورد يحمل المصدر والترخيص والنسخة وسجل التعديل.
6. **Security:** لا أسرار أو بيانات خاصة في المستودع؛ اتصال محلي لا ينكشف للشبكة.
7. **Self-maintenance:** إصلاحات المستقبل داخل المستودع فقط بعد لقطة المصدر الأولية.
