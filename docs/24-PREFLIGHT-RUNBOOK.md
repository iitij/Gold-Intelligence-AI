# تجهيزات ما قبل البحث والتدريب — Runbook v1

**الحالة:** تجهيز هندسي فقط، ليست موافقة على التداول ولا دليل ربحية. لا توجد بيانات XAUUSD حقيقية ضمن GitHub، ولا وزن نموذج مدرب. هذا المستند يكمل [التدقيق الشامل](23-COMPREHENSIVE-MATURITY-AUDIT.md) من خلال أدوات رفض صريحة.

## 1. التحقق من بوابات القبول

`planning/preflight_gates.json` يحصي G0..G6 وكل شروط القبول، وكلها **محجوبة افتراضيًا** حتى يقدم فريق المشروع أدلة مراجعة يدوّنها داخل الملف وتخضع إلى Pull Request. لا يسمح تعديل حالة gate دون إثبات كل شرط. لا يرسل `preflight.py` أي أوامر ولا يدرّب نماذج؛ حتى نتيجة ATTESTED لا تعني السماح بالتداول.

```bash
python scripts/preflight.py status
python scripts/preflight.py check training
python scripts/preflight.py check demo
python scripts/preflight.py check production
```

ترجع أوامر `check` رقم الخروج 2 (BLOCKED) عند عدم استيفاء المتطلبات، وهذا **متوقع حاليًا**. حتى لو أعيدت حالة مستقبلاً إلى accepted، فالتشغيل الحقيقي ممنوع افتراضيًا داخل النواة ويحتاج مراجعة تنفيذ وحوكمة أخرى مستقلة.

## 2. جرد الجهاز دون كشف معلومات شخصية

على جهاز Ubuntu المالك فقط وبعد استنساخ المستودع:

```bash
python scripts/local_inventory.py --output .local/hardware_inventory.json
```

يقرأ اسم طراز CPU، الذاكرة الإجمالية، المساحة الحرة، إصدار Python/Wine وطراز GPU/VRAM إن توفر. لا يجمع أسماء المستخدمين أو مساراتهم أو أرقام حساب الوسيط أو IP أو كلمة المرور أو مفاتيح MT5. **المجلد `.local/` مُستثنى من Git**؛ لا ترفع التقرير إن احتوى بيانات لا تود مشاركتها. راجع ما تجمعه الأداة قبل تنفيذها.

## 3. إعدادات GitHub

المستودع خاص، لكن Branch protection لم تكن مفعلة عند التدقيق. GitHub API أرجع تقييدًا على Rulesets في الخطة الحالية. الحفاظ على Private شرط؛ لا تحول المستودع إلى Public لمجرد حماية الفرع. الحل المؤقت: PR إلزامي بإجراء الفريق، لا merge إلا بعد CI ومراجعة، ولا Push مباشر إلى `main`؛ **ليس حماية تقنية مفروضة**.

قالب المراجعة يجب أن يذكر: نطاق التغيير، عدم فتح صلاحيات تداول، نتائج CI، أثر البيانات والتوقيت، تراخيص الشيفرة المنقولة. مراجعة الملف لا تعني سلامة المصدر أو عدم وجود ثغرات.

## 4. ما يزال مطلوبًا ولا نصنفه «منجزًا»

- بيئة CI مثبتة بالكامل بحزم وأوزان SHA؛ وبناء Offline مع SBOM وفحص ثغرات ومراجعة التراخيص.
- فحص VRAM/RAM/Wine وMT5 على جهاز المالك وتجميع `mt5/ExportXAUUSD_M15.mq5`.
- بيانات الذهب المسموح باستخدامها من وسيط محدد مع مواصفات عقد وتوقيت UTC/DST.
- Baseline ثم LightGBM/CatBoost ووحدة Replay وتكاليف صفقات واقعية.
- لا نستورد المزيد من روبوتات التداول حتى تنجح سلسلة بيانات → تدريب → محاكاة ذات معيار قبول.

## 5. كيف نتعامل مع أدلة المهام

لا تضع `done` تلقائيًا. سجّل تقدمًا جزئيًا `in_progress` مع روابط PR/CI ولو أن Issue ما زالت مفتوحة. لا يتم إغلاق Issue قبل اجتياز شروطها بالكامل. لا تقل إن مشروع Vendor «مدمج تشغيليًا» لمجرد أرشفته أو تطابق SHA.
