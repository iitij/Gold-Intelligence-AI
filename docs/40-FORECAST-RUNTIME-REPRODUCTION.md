# إعادة إنتاج بيئة التنبؤ على CPU

قفل `requirements-forecast-cpu-linux-py311.lock` يثبت الحزم الـ81 المثبتة
التي استُخدمت في تجارب NHITS وChronos-2، مع بصمات توزيعاتها. التقطنا
الإصدارات الموجودة دون ترقيتها، ثم اختبرنا توافقها وإعادة التنبؤ في بيئة جديدة.
النطاق: CPython 3.11 على Linux x86_64 مع glibc 2.28 أو أحدث.

## البناء والتحقق

```bash
uv venv --python 3.11 .local/repro-forecast
uv pip install --python .local/repro-forecast/bin/python \
  --require-hashes --only-binary :all: \
  --default-index https://pypi.org/simple \
  --find-links https://download.pytorch.org/whl/cpu/torch/ \
  -r requirements-forecast-cpu-linux-py311.lock
uv pip check --python .local/repro-forecast/bin/python
```

بديل رابط عجلات PyTorch هو مخزن عجلات محلي؛ تحقق البصمة يظل إلزاميًا.
التجربة المحلية استعملت `.local/forecast-wheels` الذي يحتوي العجلة السابقة
نفسها. اسم العجلة:
`torch-2.15.0+cpu-cp311-cp311-manylinux_2_28_x86_64.whl`، وبصمتها:
`cee15855a32ad89a9bb27b8a9d6e07a859dcd2e11ed1b5561f3d6206e31a103b`.
لا تُضاف العجلات أو الأسعار أو الأوزان إلى Git.

## إعادة نتائج النماذج المحفوظة

تحتاج هذه الخطوة إلى الملفات المحلية الناتجة عن التجارب السابقة؛ لا تُنزّل
أسعارًا جديدة ولا تعيد تدريب النماذج.

```bash
.local/repro-forecast/bin/python scripts/reproduce_forecast_runtime.py \
  --lock requirements-forecast-cpu-linux-py311.lock \
  --panel artifacts/forecast-panel-20261117 \
  --nhits artifacts/nhits-20261117 \
  --chronos-model .local/chronos-2 \
  --chronos-reference artifacts/chronos-20261118 \
  --output artifacts/forecast-runtime-reproduction
```

الأداة تتحقق من تطابق مجموعة الحزم كاملة، وبصمات لوحات البيانات وأوزان
NHITS وإعداداته، ثم تعيد مقاييس التحقق والاختبار للوسيطين. تعيد أيضًا
تشغيل Chronos-2، الذي يتحقق من بصمة أوزانه المثبتة، وتقارن صفوف التنبؤ
والأعمدة العددية كلها بالملفات السابقة. السماح العددي الأقصى `1e-6`.
اختلاف الحزم أو البيانات أو النموذج أو النتائج يمنع إصدار تقرير نجاح.

التقرير المحلي: `artifacts/forecast-runtime-reproduction-20261118/report.json`.
يسجل بصمات المدخلات والنماذج والقفل، فروق المقاييس، فروق تنبؤات Chronos،
وزمن إعادة التنبؤ على هذا الجهاز. الزمن يشمل عبء التجربة الدُفعية ولا يمثل
ضمانًا لزمن استجابة خدمة تداول.

## النتيجة المحلية في 2026-11-18

نجح تثبيت 81 حزمة في بيئة جديدة مع التحقق الإلزامي من البصمات، ونجح
فحص توافق الاعتماديات. تطابقت مقاييس NHITS الأربعة تمامًا، وتطابقت
ملفات تنبؤ Chronos الأربعة بالبايت والبصمة (6,976 صفًا إجمالًا).
استغرقت عملية Chronos الفرعية نحو 7.24 ثانية؛ زمن NHITS لكل دفعة
كان بين 0.030 و0.060 ثانية بعد تحميل النموذج. هذه قراءة واحدة على الجهاز
المحلي وليست معيار أداء عامًّا. نجحت اختبارات المشروع الـ244، ورفضت
الأداة ثلاث حالات فساد فعلية للحزم واللوحة والأوزان قبل الاستدلال وإنشاء
مجلد المخرجات؛ دليلها `artifacts/forecast-runtime-negative-controls-20261118.json`.

## ما تثبته التجربة

هذه إعادة استدلال على CPU لنماذج محفوظة. لا تثبت حتمية التدريب العصبي،
ولا تعيد إنتاج GPU أو MT5 على Windows، ولا تقفل نظام التشغيل أو نسخة
ملف Python أو مكتبات النظام. تقرير التوافق يختبر الاعتماديات؛ ليس اعتمادًا
أمنيًا للحزم. النتائج التاريخية سبق الاطلاع عليها، ونتيجة المقارنة مع خط
الأساس لا تتغير بسبب إعادة البناء. بروتوكول الاختبار المستقبلي المسجل
وملفاته المجمدة يبقيان كما هما.
