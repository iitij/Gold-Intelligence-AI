# أدوات XAUUSD للوكيل المحلي

أضيف عقد أدوات محلي يقبل رمز XAUUSD فقط. يثبت التطبيق وقت UTC
ومعرفات اللقطات وبصمات المرفقات قبل إتاحتها للوكيل. حقول استدعاء
الأداة محصورة في الرمز ومعرّف الاستراتيجية عند طلبه.

| الأداة | البيانات التي تعرضها |
| --- | --- |
| `get_gold_market_snapshot` | Bid/Ask والشموع المغلقة وخصائص السعر وأدلتها |
| `get_gold_forecasts` | الاحتمالات البحثية الستة وبصمات النماذج، إذا كان المرفق مستلمًا واللقطة صالحة |
| `get_macro_events` | القيم المتاحة والأحداث المعروفة، مع حالة تغطية التقويم |
| `get_strategy_spec` | فرضية مسجلة من سجل الاستراتيجيات وبصمة السجل |
| `get_risk_status` | امتناع محدد وأسباب النقص وموقف اعتماد التنفيذ |

تعرض الأدوات المرفقات المنسوبة إلى اللقطة نفسها. يرفض عقد
التوقعات حالة الجاهزية الواردة من المرفق ومعرّفًا من لقطة مختلفة.
تتحقق الأداة من البصمة قبل قراءة ملف المرفق. يحجب عقد الوقت بيانات
السعر والتوقعات والماكرو قبل إتاحتها وبعد انتهاء صلاحية اللقطة.
عند نقص التقويم تظل الأرقام المعروفة متاحة للتحليل البحثي، ويظل
القرار `NO_TRADE`. تحدد الأداة هذا القرار بسبب عدم اعتماد
النماذج ونقص مدخلات مخاطر الحساب أيضًا. العقد لا يحتوي وظائف حساب
صفقة أو اتصال وسيط.

يعيد `scripts/replay_gold_tool_contract.py` تشغيل العقود على أدلة
محلية. يقبل معرف لقطة السوق ومعرف لقطة الماكرو إن وجدت، وبصمة
وتوقيت استلام كل مرفق، ووقت `--as-of` المثبت من التطبيق.
مسارات الملفات وأوقاتها خيارات لبرنامج التحقق المحلي فقط.
تعريفات الوظائف تقبل إدخالها في طبقة الوكيل عند اختبار نموذج محلي.
اختبار هذه الخطوة استدعى الأدوات مباشرة باستخدام البيانات الفعلية.
تكامل الرسم البياني لـTradingAgents وتشغيل Ollama/Qwen ما زالا
قيد العمل.
