## طبقة بحثية أولية تم تنفيذها بعد التدقيق

- `src/goldintel/research/point_in_time.py`: إنفاذ أوقات UTC وإغلاق الشموع وتوافرها عند لحظة القرار لخصائص M15/H1/H4 باستخدام عينات اصطناعية؛ يمنع مراجعات الماكرو المستقبلية.
- `src/goldintel/research/labeling.py`: تسميات OHLC افتراضية ترفض كسبًا مفترضًا عند غموض ترتيب لمس وقف/هدف؛ لا تمثل تنفيذًا عند الوسيط أو عائدًا بعد السبريد.
- `src/goldintel/research/splits.py`: تقطيع زمني أمامي مع Purging وEmbargo وحظر نتائج التوسيم التي لم تكن معروفة قبل الاختبار؛ ما يزال بلا Dataset حقيقي أو Walk-forward متكامل.
- نجحت اختبارات CI لآخر PR، مع استمرار النجاح على المستودع الرئيسي عند دمجه. [الدليل الفني](20-POINT-IN-TIME-FOUNDATION.md).

## خارج نطاق ما تم تنفيذه حتى الآن

- **لا توجد بيانات XAUUSD فعلية مؤكدة أو مدققة لدى وسيطك**؛ لم يجرِ اختبار سكريبت MQL5 داخل MetaEditor أو تحديد منطقة توقيت السيرفر وتاريخ DST.
- **لا تدريب فعلي** لـLightGBM أوCatBoost أوNHITS ولا تخصيص Qwen/Chronos، ولا نموذج مستخدم لاتخاذ قرارات سوق موثقة.
- **لا نتائج Backtest تخص مشروعنا** على أسعار Bid/Ask/Tick وبروتوكول مستقل؛ نتائج Aurum الخارجية لا تمثل نتائجنا ولا تثبت الربحية.
- **لا مجلس وكلاء محلي يعمل**، ولا Bridge للتنفيذ، ولا تداول ورقي متصل بالسوق أو حساب MT5 تجريبي أو حقيقي.
- نقل الشيفرة لا يثبت أمنها؛ **لا SBOM مفصل أو فحص شامل للتبعيات**، وبيئة Python/Actions لم تثبّت كلها بأرقام SHA وحزم محكمة.
- **حماية الفرع الرئيسي غير مفعلة** في إعدادات GitHub كما ظهر أثناء التدقيق، ولا تُعتبر سياسة المراجعة مكتملة.
- لا تتوفر لدينا نتائج فحص VRAM/RAM/SSD أو صلاحية بيئة Wine الحالية؛ لا نصدر أوامر تغيير على جهاز المالك دون بياناتها.

## ترتيب التنفيذ الصحيح (المسار الحرج)

1. **P00-02**: تفعيل ruleset لحماية `main` ومنع force-push واشتراط CI.
2. **P01-05 / P02-02**: جرد اعتماديات وشيفرات المنبع، SBOM/CVE، ملفات lock وبناء قابل لإعادة الإنتاج، مراجعات الترخيص.
3. **P02-01 / P03-01 / P03-02**: فحص عتاد الجهاز ومواصفات رمز الذهب الفعلية، وتشغيل صادر MQL5 على MT5 تجريبي/للقراءة فقط.
4. **P03-03..P04-03**: بيانات مرخصة ومدققة، توقيت موثّق، خصائص وLabels بلا تسرب للمستقبل.
5. **P05 / P08**: تدريب Baselines ثم LightGBM/CatBoost، والتقييم الصارم بعد التكاليف.
6. **P07**: اختبار القيمة الإضافية الحقيقية لمجلس Qwen مقارنة بنظام Quant-only؛ رفض التعقيد غير المجدي.
7. **P09 / P10**: تحقق محاكاة التنفيذ والتداول التجريبي والفشل والمراقبة قبل أي قرار جاهزية للإنتاج.
8. **P11**: مسارات بحث اختيارية ذات تبعيات، لا تُفعّل دون أدلة وقواعد قبول واضحة.

**قواعد غير قابلة للتنازل:** XAUUSD فقط، no-lookahead، no-auto-upstream-sync، no-real-money-orders، مسار دائم لـNO_TRADE، وإبقاء القرار النهائي تحت قواعد المخاطر والمراجعة البشرية.
